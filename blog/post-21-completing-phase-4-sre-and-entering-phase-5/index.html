Milestone: Completing Phase 4 (SRE & Observability) and Entering Phase 5 (Governance & Reliability)

16 August 2026

Date: 2026-08-16
Author: ls0775
Category: Milestone / Architecture / SRE

1. Executive Summary

Today marks a major milestone in our homelab journey: the formal completion of Phase 4 (SRE Practices & Observability) and the transition of the project into Phase 5 (Governance & Reliability).

What started as a foundational 2-node cluster has matured into a production-like, enterprise-grade platform running on a symmetrical 3-node physical Proxmox cluster with a 6-node HA k3s Kubernetes cluster, continuous Google SRE observability, pre-computed SLO recording rules, and native Azure Key Vault secret synchronisation.

  1. Pre-computed SLOs & Error Budgets (Mitigation R-005):
    • Implemented 30-day rolling SLIs for k3s API (99.5%), Ingress (99.5%), and NFS Storage (99.9%).
    • Deployed Google SRE multi-window burn-rate alerts (14.4x fast-burn and 3x slow-burn) linked to incident runbooks.
    • Built a declarative Grafana Global SLO Reliability dashboard.
  2. Centralized Log Aggregation (Mitigation R-004):
    • Deployed Loki SingleBinary (Replication Factor 3) backed by MinIO S3 object storage, with Promtail DaemonSets scraping all nodes.
  3. Automated Remote State (Mitigation R-002):
    • Migrated OpenTofu IaC state from workstation local storage to distributed MinIO S3 backend.
  4. External Secrets Operator Cloud SSoT (Mitigation R-012):
    • Centralized 14 platform and application secrets in Azure Key Vault (kv-homelab-ls0775) with continuous 1-hour native reconciliation.
  5. Chaos Engineering & Automated Disaster Recovery Drills:
    • Authored and verified single-host failure simulation drills (test-proxmox-hardware-failure.sh) and DR snapshot restore test suites (test-disaster-recovery-restore.sh), verifying an active RPO of 4.2 hours.

3. Entering Phase 5: Governance & Reliability

With core infrastructure, networking, DevOps toolchains, and observability fully operational, Phase 5 focuses on portfolio readiness, public sharing, and continuous integration:

  • Mitigation R-006: GitHub Actions CI/CD for OpenTofu IaC plans on pull requests.
  • Formalized Error Budget Policies: Codifying release gating and blameless post-mortem cadences.
  • Public Portfolio Polish: Final secret sweeps, documentation scrubbing, and architecture showcases.

4. Platform State at Transition

  • Physical Hypervisors: pve01, pve02, pve03 (3 identical Intel NUC 7 i7 nodes, 3 Corosync votes, quorate).
  • Kubernetes Compute: 6 VMs (k3s-server-01..03, k3s-agent-01..03) on VLAN 99 (192.168.99.0/24).
  • SRE Maturity Score: Level 3 (Resilient) — 2.90 / 4.0 per Google SRE independent audit.

Next up: Phase 5 Governance, CI/CD automation, and public portfolio release!
